# Python 零基础 → 计科转专业 学习档案

> 学生：环境工程 → 目标计算机科学
> 原则：每节课都跑得起来、看得见输出、有练习、错了有人批改。

## 怎么运行代码

**方式一（最省事）**：把代码发给我，我帮你跑，把输出和报错贴回来。

**方式二（推荐，自己动手）**：装好 Python 后，在终端里：

```bash
cd python-101
./run.sh lesson01/hello.py
```

> `./run.sh` 用的是 DSH 自带的 Python，不用装任何东西。

## 学习路线

| 课 | 内容 | 你能做到什么 |
|---|---|---|
| 01 | print、变量、类型、运算、f-string | 让电脑说话，存数据、算数 |
| 02 | if / elif / else、比较、bool | 让程序会**判断** |
| 03 | for、while、range | 让程序**重复干活** |
| 04 | list、dict | 一次处理**一堆**数据 |
| 05 | 函数 | 把代码**打包复用** |
| 06 | 字符串方法、input | 和用户**交互** |
| 07 | 文件读写、异常处理 | 读写真实文件，程序**不崩** |
| 08 | 模块、pip、虚拟环境 | 用别人写好的库 |
| 09 | 调试与读报错 | 自己修 bug |
| 10 | 小项目：整理下载文件夹 | 第一个**有用**的东西 |

之后进入第二阶段：`pandas` 数据分析（用环境监测数据练）→ 一个完整项目。

## 每节课的节奏

1. 我讲一个概念（附可运行代码）
2. 你改代码，观察变化
3. 做 3–5 道练习，**先自己写，允许写错**
4. 我批改，解释你哪里想偏了
